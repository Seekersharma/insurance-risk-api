# Insurance Knowledge Skill

## Purpose

Use this skill whenever the user asks to:

- Explain insurance concepts
- Compare insurance products
- Describe underwriting principles
- Define policy terminology

## Workflow

1. Understand the user's question.
2. Provide a concise explanation.
3. Include practical examples when helpful.
4. Present information in business language.

## Output Format

### Overview

### Key Concepts

### Practical Considerations

### Summary

## Guidelines

- Be accurate and concise.
- Use simple business language.
- Prefer bullets over long paragraphs.
- Avoid unnecessary technical jargon.
