# Claims Analysis Skill

## Purpose

Use this skill whenever the user asks to:

- Analyze claims CSV files
- Count rows or columns
- Generate descriptive statistics
- Detect missing values or anomalies
- Produce business recommendations

## Workflow

1. Inspect the dataset structure.
2. Identify columns and data types.
3. Compute summary statistics.
4. Detect anomalies or missing values.
5. Generate concise business insights.
6. Present results in a clean markdown format.

## Output Format

### Dataset Summary

- Rows:
- Columns:
- Missing Values:

### Statistics

- Mean
- Median
- Standard Deviation

### Business Insights

- Key observations
- Potential risks
- Recommendations

## Guidelines

- Keep responses concise.
- Prefer tables over paragraphs.
- Explain findings in business language.
- Highlight unusual patterns.
