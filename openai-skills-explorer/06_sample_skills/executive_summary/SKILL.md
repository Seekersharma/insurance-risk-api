# Executive Summary Skill

## Purpose

Use this skill whenever the user asks to:

- Summarize reports
- Produce executive briefings
- Extract key findings
- Identify risks and recommendations
- Generate leadership summaries

## Workflow

1. Read the document.
2. Identify major themes.
3. Extract important findings.
4. Highlight risks and opportunities.
5. Produce concise recommendations.

## Output Format

### Executive Summary

### Key Findings

### Risks

### Recommendations

## Guidelines

- Keep responses concise.
- Use business language.
- Prefer bullet points.
- Focus on decision-making.
